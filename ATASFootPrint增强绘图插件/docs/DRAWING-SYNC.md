# Drawing Sync / 微型合约绘图同步

**1.0.1 正式版 · 2026-10-30**

独立 ATAS 指标，支持 ES ↔ MES、NQ ↔ MNQ 的原生 Global 绘图双向同步。适配 Windows、.NET 10、ATAS **8.0.15.304 / 8.0.15.306**，不依赖 Footprint Outline，也不需要网络服务。

## 安装与升级

1. 解压 `DrawingSync-v1.0.1.zip`，关闭 ATAS，用包内 `WolfMoss.DrawingSyncProbe.dll` 替换旧 DLL，再启动 ATAS；首次安装可使用 ATAS 的“添加自定义指标”导入。不要同时加载新旧两份。
2. 指标名称为 **Drawing Sync / 微型合约绘图同步**。在参与的 ES/MES 或 NQ/MNQ 图表中挂载，填写相同“同步组”并开启同步。新实例默认组名为“默认”；已有实例保留原组名。
3. 使用相同数据源及对应合约月份/合约类型。支持原生主连，允许不同图表周期以及同组多张大合约、多张微型合约图。
4. 用 ATAS 原生工具绘制并勾选 **Global / 全局**。完成绘制、松开鼠标后同步，通常在下一个约 300 ms 的检测周期处理。
5. 状态文字应为 `Drawing Sync 1.0.1`。可调整文字纵向位置或关闭显示，完整状态仍可在指标设置的“诊断 → 当前状态”查看。

**升级保留 DLL 文件名、程序集名、指标类型及原配对记录路径，供旧工作区继续识别。**文件名中的 `Probe` 仅是兼容标识，UI 与发行版本已为正式版。不要清空配对记录或随意更换已有组名，否则已有镜像可能被当成独立绘图重新配对。首次连接两侧不一致时，大合约侧优先。

## 支持的绘图及属性

| 原生工具 | 同步内容 |
| --- | --- |
| 水平线 `HLine` | 价格、颜色、粗细、线型、文字、文字大小/位置、隐藏价格标签 |
| 水平射线 `HorizontalRay` | 水平线的上述属性，以及起点时间 |
| 矩形 `RectangleObj` | 两个时间/价格锚点、边框、填充颜色/透明度、文字及水平/垂直位置、左右延伸、中线开关/颜色/粗细/线型 |
| 趋势线 `TrendLine` | 两个时间/价格锚点、颜色/粗细/线型、两端箭头、文字/背景色/字体大小/字体/粗体/斜体/下划线/删除线，以及普通线段、射线、双向延长模式 |

“射线”包含独立水平射线和趋势线工具的射线模式。原生价格直接复制，不按合约乘数缩放。时间以原生时间戳保存，目标图按自己的周期映射到 K 线；目标图需加载相应历史，不保证不同周期的像素位置和宽度一致。矩形文字字体由各图原生字体决定。

不复制警报、锁定/隐藏、周期可见性、水平线价格文字的专属颜色，或矩形的特殊蜡烛/网格/方向色/额外比例设置。新建镜像关闭接近及穿越警报。只处理表中四个精确原生类型，不处理子图、指标绘图、订单对象或其他衍生工具。

## 保留的同步规则

- 只同步已完成、开启 Global 的主图对象；普通本地对象不会被复制。
- 同组多图共享每个合约侧的一份原生 Global 对象。`配对 4 | 图表 2+3` 表示四组绘图配对，而不是每张图各创建一份镜像。
- 任意一侧新增、移动、调整样式、删除均可传播。删除后有效配对数下降；最多保留 256 个已删除配对 ID 供原生撤销恢复，不计入有效数量。
- 对已经确认的全局配对取消 Global：保留 ATAS 留在操作图上的本地对象，删除另一合约侧镜像，解除配对；同品种其他窗口的显示由 ATAS 撤去。再次开启 Global 会重新配对。若两侧均在检测前转成本地，则保留两条本地对象并解除配对。
- 关闭图表、离组或关闭同步不会删除绘图。重开图表、重新加入时复用旧 ID，缺失的一侧从仍存在的全局绘图补齐；两侧都不存在不会凭空恢复。插件没有观察到的离线删除不会当作删除指令。
- 同一检测周期双方同时修改时，大合约侧优先。不同 ID 的独立绘图，即使位置和样式相同，也不强行合并。
- 已存在但未完成、缺少时间锚点、类型不符的对象会暂挂，避免误删另一侧。

ATAS Global 按品种共享，可出现在未挂载插件的图上，也可能跨同品种月份显示。**同步组不是可见性隔离边界。**同一合约族只允许一个完整同步组、一个月份/合约类型同时运行，避免镜像互相复制；单侧未配齐的其他组只等待。ES/MES 与 NQ/MNQ 两族可以同时运行。

支持平台返回到期月为空、`Instrument.Continuous=true` 且名称为 ES/MES/NQ/MNQ 的原生主连。不猜测图表标题中的月份，不自动调整换月价差。明确月份合约须匹配月份与历史模式。只支持同一 ATAS 进程、同一 GUI 线程；回放仍暂停同步。之后 ATAS 升级到未验证版本时显示版本警告并继续同步，不再仅因版本号不同暂停；实际接口缺失或原生读写校验失败时仍停止。

0.1.x 的旧本地配对仍保留。若需要继续同步，应先将旧配对**两侧**都开启 Global；仅一侧开启时暂挂，防止覆盖另一侧本地绘图。0.2.x/0.3.x 已确认的全局配对可直接沿用。

## 性能与持久化

- 每个同步组约 300 ms 执行一轮，同组图表增加不会按窗口数量重复扫描绘图。
- 每侧读取一份共享原生快照；全局存储的辅助扫描在本轮复用。各图仍保留轻量心跳与就绪检查。
- 只写入状态变化的对象。没有变化时不保存原生对象、不写配对文件、不请求刷新。
- 批量新增的映射合并为一次持久化写入；混合新增/解除配对最多两次。先保存新映射，再创建；删除完成并通过原生回读校验后再移除旧映射。
- 对象按 ID 查找，修改一批对象后每个被修改侧只做一次完整回读校验和状态通知，避免逐条重扫。
- 原生类型/字段/方法元数据缓存；绘图快照只保留不可变值，字体和中线设置不会跨对象共享可变引用。
- 每组最多 2000 个未删除配对（含暂挂），每侧读取的原生对象最多 2000 个。达到上限停止新增，清理后重新启用。

配对记录位于 `%LOCALAPPDATA%\WolfMoss\DrawingSyncProbe\`，只保存组/品种作用域和对象 ID、类型、全局配对标记。原生绘图由 ATAS 保存。文件原子替换并刷新到磁盘，文件锁防止另一进程同时操作相同记录。取消插件不会移除已创建的原生绘图。

性能检查覆盖 100/1000/2000 个混合配对、20 张图表心跳、无变化零写入及批量持久化次数。包内 `TEST-RESULTS.txt` 包含本机纯引擎计时；该计时不含 ATAS 图表渲染、原生存储或磁盘耗时，不能当作实际 CPU 占用承诺。

## 验证范围

构建与自动化回归覆盖双向新增/编辑/删除/撤销、重连、取消 Global、多图去重、旧记录兼容、故障后记录保留，以及当前安装版本的真实原生对象与隔离存储。矩形中线、水平射线起点、趋势线三种模式/箭头/字体均有原生属性回读检查。

测试不连接行情、不操作运行中的图表。完整 GUI 显示、真实工作区保存/恢复与 ATAS Ctrl+Z 历史栈仍需实机验收；这次发行未把离线测试描述为实盘图表验证。

升级后可在同组 M5/M30 图上分别画四类 Global 对象，修改端点/样式/矩形中线与趋势线模式，反向修改，再取消 Global、删除、撤销及重开图表。确认配对数正确、无重复对象即可。

## 构建与扩展

```powershell
.\tools\Build-DrawingSync.ps1
# 非默认安装路径：
.\tools\Build-DrawingSync.ps1 -ATASInstallDir 'D:\ATAS Platform'
```

发行物位于 `dist/DrawingSync/`；旧构建脚本转调正式版脚本。适配层使用未公开的原生接口，启动时检查实际接口；版本号差异仅产生警告。扩展类型及内部机制见 `ARCHITECTURE.md`（源码为 `docs/DRAWING-SYNC-ARCHITECTURE.md`）。
