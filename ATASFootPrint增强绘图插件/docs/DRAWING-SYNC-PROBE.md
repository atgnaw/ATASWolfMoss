# Drawing Sync Probe / 微型合约画线同步验证

> 本文保留 0.3.1 验证版历史。当前正式版安装与功能说明见 [DRAWING-SYNC.md](DRAWING-SYNC.md)。

版本：**0.3.1**。适配：Windows、.NET 10、ATAS **8.0.15.304**。独立指标 DLL，不依赖 Footprint Outline。

0.2.2 增加“关闭 Global 即解除同步”：对本版已确认同步的全局水平线，在任意大/微合约图取消 Global，保留 ATAS 留在操作图中的本地线，删除另一合约侧的全局镜像，移除配对记录，配对数下降且不再暂挂。同品种其他图中的显示由 ATAS 的全局属性自动撤去。再次开启 Global 会创建新的镜像配对。只删除该 ID 对应的镜像，不删除同价但独立绘制的线。

升级前已经处于“一侧本地、一侧全局”的旧配对，无法区分是以前取消全局，还是正在把旧本地线升级为全局，因此仍暂挂。请先让两侧都开启 Global 并在新版显示有效配对，再取消需要保留的那条线的 Global。本版会保存“已确认全局配对”的标记，之后重新挂载也能识别取消全局。若两侧都在一次检测前取消 Global，保留两条用户明确转为本地的线并解除配对。

0.2.1 修正了“尚未配齐的组也让其他组暂停”的问题。例如一张 ES 误填 A、另两张 ES/MES 填 AA，现在 A 组只显示等待，AA 组继续同步；若希望三图全部参与同一组，应统一填写 AA。正常、等待及冲突状态显示组名，冲突详情列出图表编号和合约类型。只有同族同时存在多个完整配对组时才阻止并行写入，避免全局镜像互相复制。配对文件格式和作用域保持不变。

0.3.1 补充矩形中线同步：只修改中线也会双向同步；中线关闭时仍同步其样式，以便再次开启。已有矩形无需重画，沿用原组名和配对记录。首次升级连接时若两侧设置不一致，按既有规则以大合约侧为准，之后任一侧修改均可同步。

## 矩形支持

矩形沿用全局属性、同组多图、双向修改/删除、重开图表补齐、取消 Global 保留本地并删除镜像的规则。水平线与矩形共享同一组和配对总数，原水平线配对记录可直接沿用，不需清空。

同步矩形的两个原生时间锚点、两个价格、边框颜色/粗细/线型、填充颜色/透明度、文字及水平/垂直位置、左右延伸属性，以及中线开关、颜色（含透明度）、粗细和线型。复制原生时间而非源图 K 线序号，目标图由 ATAS 按自己的周期映射到对应 K 线；不同周期会按各自 K 线边界显示，不保证像素宽度相同。目标图需加载对应时段的历史数据。

矩形的特殊蜡烛/网格/方向色模式、额外比例、警报、锁定/隐藏和时间框架可见性设置暂不同步。文字字体使用各图表原生字体。绘制到第二个角点并松开鼠标后才同步；未完成或缺少时间锚点时不创建镜像。

建议在 M5/M30 图上新建一个 Global 矩形，分别测试整体移动、拖动角点缩放、填充颜色和文字修改，再从微型合约侧取消 Global，确认只保留该图中的矩形，其他图对应矩形消失，水平线不受影响。

## 已有规则

- “配对”显示当前有效的全局水平线和矩形配对总数，删除后立即下降。后台只保留最多 256 组已删除 ID 记录供撤销恢复使用，不计入配对数，也不再无限积累。
- 关闭图表后重新打开、挂载指标，会复用现有全局对象；配对另一侧确实缺失时，从保留下来的全局线补齐，使用原配对 ID。
- 同组支持多张 ES 与多张 MES，或多张 NQ 与多张 MNQ。每侧共享一份 ATAS Global 对象，按原生 ID 去重，不按窗口数量创建重复镜像。
- **仅同步开启 Global / 全局的主图水平线和矩形**；未开启全局的对象不参与同步。新建镜像也开启全局。

## 安装和启用

1. 关闭 ATAS，替换原 `WolfMoss.DrawingSyncProbe.dll` 后重启；或通过“添加自定义指标”导入新版。不要同时保留加载两份新旧 DLL。无需删除配对记录。
2. 在各张 ES/MES 或 NQ/MNQ 图上挂载 **Drawing Sync Probe / 微型合约画线同步验证**。填写相同同步组，开启同步。
3. 使用相同数据源、相同月份/合约类型；也支持用户截图中的 `#ESZ6 / #MESZ6` 对应原生主连。各图可以使用不同周期。
4. 用原生 **Horizontal Line / 水平线** 或 **Rectangle / 矩形** 绘制，并勾选 **Global / 全局**。在任一侧新增、移动、修改样式或删除，观察各图同步。
5. 左上角应显示 `Drawing Sync 0.3.1`。例如 `组「AA」 ... 配对 1 | 图表 2+3 | 全局水平线/矩形` 表示一组大/微合约镜像、两张大合约图及三张微型合约图。

“配对 1”不随窗口数增加。新开同品种图会由 ATAS 显示已有全局线，挂载指标并加入同组后继续跨大/微合约同步。新加入前没有同步观察到的删除，不会被当作删除命令；如果仍有另一侧全局线，会补齐。

## 从 0.1.x 升级

原来的本地线不自动改成全局线，也不删除。旧配对 ID 继续保留，因此需要继续同步的**旧配对两侧都应勾选 Global**，这样可复用配对而不重复创建。若只有一侧勾选，另一侧仍是本地对象，这一对会暂挂，防止修改被要求忽略的本地线。两侧都未勾选时不计入有效配对数。

新画的 Global 线没有此迁移要求：任意一侧画一条，插件会在另一侧创建 Global 镜像。本版确认同步后取消 Global 会解除配对并删除另一侧全局镜像，保留当前本地线。

## 同步规则与边界

- 支持原生 `HLine` 主图水平线和 `RectangleObj` 主图矩形，不包含水平射线、趋势线、其他矩形衍生工具、子图对象、指标绘制线或订单对象。
- 同步价格、颜色、线宽、线型、文字、文字大小/位置和是否隐藏价格标签。价格原值复制，不按合约乘数缩放。
- 不同步警报、锁定/隐藏、价格文字专属颜色和时间框架可见性设置；新镜像关闭穿越及接近警报。若原生线的周期可见性被限制，其他周期可能看不到它。
- ATAS 原生 Global 对象按品种共享，可出现在没有挂载插件的同品种图上；原生规则还可能让它跨该品种的合约月份显示。**同步组不是全局线的可见性隔离边界。**为防止不同引擎互相复制，同一合约族只允许一个同步组、一个月份/合约类型同时运行；所有参与图请统一这些设置。ES/MES 与 NQ/MNQ 可以同时运行。
- 对应原生主连支持平台返回 `Name=ES/MES/NQ/MNQ`、到期时间为空且 `Instrument.Continuous=true` 的情况。不猜测标题中的实际到期月，也不自动调整换月后的价位。明确月份的合约仍须对应月份一致。
- 同一进程、同一 GUI 线程内同步。回放图或不支持的 ATAS 版本暂停；不绕过版本校验。
- 约 300 ms 检查一次；鼠标左键按下时等待，拖动松开后同步。
- 不同 ID 的独立线，即使同价同样式，也不会强行合并。两边原来各画一条同价 Global 线，初次合并后每边会有两条。
- 同一检测周期双方同时修改同一对线时，大合约侧优先；重连时双方内容不一致也以大合约侧为准。
- 持续连接期间已确认的删除会传播；关闭图表、离组、停止同步不是删除。重连时缺一侧就从另一侧补齐；两侧都不存在不会凭空恢复。
- 保留的删除 ID 支持识别原生 Undo 恢复；超过 256 条删除记录后，较早 ID 再恢复会当作新线。ATAS 实际 Ctrl+Z 历史栈仍需实机验收。
- 已确认的全局配对中，完成的主图水平线或矩形变为非全局时执行解除配对。其他类型、子图对象或未完成对象仍暂挂，不当作取消 Global 的命令。
- 错误时停止写入。排除问题后关闭并重新启用同步；状态文字过长时，在指标设置“诊断 → 当前状态”读取完整消息。

## 配对记录

记录在 `%LOCALAPPDATA%\WolfMoss\DrawingSyncProbe\`，只保存同步组/品种身份及对象 ID 配对。原生图形由 ATAS 保存。JSON 原子替换，文件锁防止多进程同时使用同一配对记录。先持久化配对再创建镜像。

请保留原组名和记录；删除记录或更换组名，会使已有镜像被当作独立新线。当前未删除配对（含被暂挂的旧配对）上限 2000，另保留最多 256 条删除历史；单图可见对象上限 2000。关闭插件不会删除已创建的原生线。

## 验证情况与实机验收

自动化检查覆盖同步引擎、多图分组和重连、2100 次新增/删除循环、旧版配对迁移、文件锁与损坏处理，以及隔离创建的**真实 ATAS 原生对象存储**。原生测试验证了 Global 跨图共享、非 Global 过滤，以及关闭创建图后全局对象仍可在新图读取。

这些检查不连接行情、不操作正在运行的图表；完整 GUI 显示、工作区保存恢复和真实 Ctrl+Z 尚需实机验证。测试结果见包内 `TEST-RESULTS.txt`。

建议验收：

1. 一张 ES、两张 MES 同组；ES 新建 Global 水平线，三图均只出现一条。未勾全局的线不跨合约同步。
2. 再加入一张 ES、一张 MES；状态为 `图表 2+3`，配对数仍为 1，没有新增重叠线。
3. 在任一 MES 修改价格/颜色，所有相关图跟随；删除后配对变成 0。
4. 保留一条全局线，关闭全部 MES，再重开 MES 并挂载指标；旧线可见并能继续修改同步。
5. 保存工作区并重启 ATAS，检查配对不重复；再验证 NQ/MNQ、不同图表周期及原生撤销。

## 构建

```powershell
dotnet build .\DrawingSyncProbe.slnx -c Release
dotnet run --project .\tests\DrawingSyncProbe.Tests -c Release
.\tools\Build-DrawingSyncProbe.ps1
```

发行包位于 `dist/DrawingSyncProbe/`。通过反射适配未公开的原生接口，严格限定 ATAS 8.0.15.304。
