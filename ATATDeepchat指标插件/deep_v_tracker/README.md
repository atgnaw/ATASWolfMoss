# Deep-V Tracker · TradeVant C++ 指标

这是依据 Deepchart 16.5.4 中 `OrderedCompressorEvaluator` 的可读 C# 恢复结果移植的 TradeVant 指标。
它通过公开 PluginSDK 订阅真实逐笔成交，输出加速区域、两套衰竭标记、可变减速标记和吸收 / 压力水平线。

## 图表与阈值

指标按所在图表的柱计算：开柱、收柱、柱索引和最近 N 根柱都取自宿主交付的柱，任何柱周期都能用。逐笔成交是另一层输入：
SDK 的 `onTrade` 给出价格、数量、主动方向和撮合时间，插件据此累计 Bid/Ask 成交量、分价量和成交记录数；成交记录数用于第二套
衰竭检测，不用来划分柱。

同原版，吸收 / 压力与减速的几项阈值按图表分两套，由图表的柱周期自动选，没有对应的参数：

| 项目 | Range 图（N tick） | 其余图表 |
| --- | --- | --- |
| 窄幅区间的最少柱数，减速标记的回看柱数 | 4 | 5 |
| 窄幅区间的实体跨度上限（tick） | N + ⌊N / 2⌋ | ⌊max(1, 0.85 × 最近 21 根柱真实波幅的均值)⌋ |
| 离开区间要超过的距离（tick） | ⌊N / 4⌋ | ⌊跨度上限 / 0.85 × 0.2⌋ |
| 区间内单柱量门槛的标准差倍数（弱 / 中 / 强） | 0.7 / 1.0 / 1.3 | −0.5 / −0.3 / 0 |
| 减速价区的跨度超过多少 tick 就重新开始 | 2N | 8 |

Range 图只指周期面板上的 Range（柱内高低差最多 N 个 tick），对应原版唯一的 Range 图；Range X、Range XV、Range Z、成交量、Delta
与按时间分出的柱都按其余图表计算，同原版在 Volume、Trade、Renko 等图上一样。其余图表的真实波幅要攒满 21 根，第 22 根柱收盘前
不识别窄幅区间。

TradeVant 的 Range 柱按 ATAS 的规则构造，与 Deepchart 的 Range 柱是否逐根相同没有核对；与原平台在同一行情上的逐信号对照也还
没有做。

## 构建与使用

主工程使用 `scripts/build.ps1 -Target deep_v_tracker`；输出包位于所用构建预设的
`bin/indicators/deep_v_tracker/`。把整包放入与构建时 SDK ABI 相同的 TradeVant 指标目录，选择 **Deep-V Tracker**。
包包含 DLL、生成的清单及 `parameters.schema.json`，不依赖 Deepchart 运行时。

也可独立构建此目录：安装本仓库 PluginSDK 和 `nlohmann_json` 后，以 CMake 3.27 以上版本配置此目录。
插件只链接公开 SDK，不访问 TradeVant 应用私有代码。

默认四类强度为 `medium`，位置模式为 `conservative`，水平线最长延展 10 个柱索引跨度。

## 计算与显示

| 功能 | 输入及规则 | 显示 |
| --- | --- | --- |
| Acceleration | 首笔撮合时刻起的约一秒成交桶；候选峰值加入统计后比较异常阈值 | DimGray 区域，原规则最长延展 12 个柱索引跨度 |
| Exhaustion | 收柱后的滚动 Delta 转向、方向段峰值统计；成交量与成交记录数各一套 | 实心三角为成交量、空心三角为成交记录数 |
| Slowdown | 逐笔局部价格区间的三档 Bid / Ask 量与窄幅区间可见性 | 较粗空心三角；可移动、翻向、隐藏或重新出现 |
| Absorption / Pressure | 窄幅实体区间、离开条件、区间 Delta、完整分价 POC 与原规则价值区扩展 | AC / AE 为虚线，PC / PE 为实线；颜色取区间 Delta 符号 |

未知主动方向仍计入真实总成交量及分价总量，但不会被猜成买或卖。该柱的衰竭、减速与新水平线判断停用，
相关滚动状态重新建立；加速总量检测继续。图中以输入资格提示解释缺失。成交记录数逐条计数，不能当作独立订单数量。

## SDK 适配约定与原版差异

- SDK 先调用 `onTrade`，再交付已包含该笔的 `onBar`。适配器先保存只含数值的待配对逐笔，在两者身份一致后依次收旧柱、
  开新柱、累积新成交。分价分布完全来自逐笔价格和主动方，不使用 OHLC 合成分价量。
- 原版在加载时读图表；SDK 创建实例时不给柱周期，插件在第一根柱开出时按上下文的柱周期选定上表的阈值。改周期由宿主新建
  实例重算，同一实例中途换了周期按错误处理。
- `onClock` 只确认真实柱收盘并去重；不会在空闲秒中生成成交桶或空柱。播放、历史重建和检查点复制使用相同计算路径。
- 原版 `OnEnd(false)` 没有对应的 SDK 批次事件。这里在每次确定的 Trade → Bar 配对结束后执行一次，额外墙钟回调不执行它。
  因而减速的中间显示刷新时点不承诺与原宿主的批次调度逐帧一致。
- 原图形使用的 `barIndex+1` 只在渲染时偏移 X。记录锚定已经观察到的真实柱，不将信号提前发布到未来柱。
- 跨合约时在旧合约最后一柱冻结活动图形，新合约重新预热所有检测器；记录序号延续，旧历史不会被新信号覆盖。
  同一柱被合约边界截断时明确标记输入不完整，不拼接两个合约的 Delta。
- 本实现用 SDK 三角形替代原版专有图标资源；字体由宿主提供，DIP 尺寸不重复乘 DPI。加速颜色默认 DimGray，
  衰竭 Cyan、减速 Gold；Ask / Bid 线色可配。外观参数支持 `restyle`，修改计算参数由宿主重建。
- 没有移植声音、弹窗、账户动作或交易执行；不提供无限延伸及原 `ExtendFarRight` 选项。
  水平线投影上限为 1024，以限制同次收柱发布预算。
- 输入乱序、身份不匹配、非 tick 网格价格、整数溢出或宿主拒绝记录会产生明确错误，经 SDK 隔离该实例。

本移植保留已识别的原规则特殊行为，包括候选先入统计、零 Delta 归非负侧、首次加速计数器以 PinT 初始化、
价值区扩展累计量不先加 POC、两侧同量优先向下、Strong 使用 High / Low 离开确认。
这些规则不应替换为平台通用算法后仍宣称逐项一致。

## 代码职责

| 文件 | 责任与依赖 |
| --- | --- |
| `model.*`、`statistics.*` | 价格 tick、UTC 纳秒、参数、信号与有界统计值，不依赖 SDK |
| `acceleration.cpp`、`exhaustion.cpp`、`slowdown.cpp`、`patterns.h` | 三类形态的纯值状态迁移 |
| `levels.*`、`profile.*` | 窄幅区间、吸收 / 压力分类及分价价值区计算 |
| `engine.*` | 协调开柱、逐笔、批次结束、收柱与有限图形延展；副本共享只读状态 |
| `calculator*` | SDK 配对校验、按柱周期选阈值、逐笔聚合、收柱去重、换月与语义记录发布 |
| `marks.h`、`renderer.*` | 可平凡复制的记录值与只读绘制，不反向推进计算 |
| `settings.*`、schema、manifest、`plugin.cpp` | 配置边界、包身份与公开 SDK 组装入口 |

实例状态不跨实例共享可变数据，不创建线程，不读取文件、网络或墙钟。计算器拷贝、渲染器重建和只读配置共同组成检查点。
编译和合成事件测试不能替代与原平台同一行情的逐信号回放对照。
