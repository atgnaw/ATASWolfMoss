# Deep-V Tracker — ATAS 版 1.0.0

将本仓库 `deep_v_tracker/` 的 C++ 检测器、事件顺序和图形延展规则移植为 ATAS 原生 C# 指标。支持成交加速、成交量与成交记录数双路衰竭、动态减速标记，以及吸收 / 压力控制线和极值线。原 C++ 文件保持原样。

## 安装

针对 Windows ATAS / **.NET 10** 构建，使用本机 **ATAS.Indicators 8.0.15.304** 编译和集成测试。

1. 解压 `DeepVTracker-ATAS-1.0.0.zip`。
2. ATAS 图表 → 指标设置 → **Add custom indicator / 添加自定义指标**，选择 `WolfMoss.DeepVTracker.dll`。
3. 搜索 **Deep-V Tracker / 成交流追踪**，添加到主图（类别 WolfMoss，平台也可能归入 Custom）。
4. 等待左上角历史逐笔加载提示结束。确保图表周期与“区间规则”匹配。

也可将 DLL 复制到 `%APPDATA%\ATAS\Indicators`，随后使用平台重新加载入口或重启。PDB 用于排错；不要复制平台自带的 ATAS/OFT DLL。本构建脚本只生成文件，不安装到正在运行的平台。

安装方式见 [ATAS 官方说明](https://docs.atas.net/en/md_DataFeedsCore_2Docs_2en_20010__BasicIndicator.html)。

## 指标原理与显示

| 模块 | 原理 | 显示 |
| --- | --- | --- |
| 成交加速 | 从首笔时刻开始分约一秒成交桶，每开一根图表柱允许一次统计采样；峰值先加入最近 50 个样本，再比较均值加标准差阈值 | DimGray 灰色区域，最大延展 12 个柱索引跨度 |
| 双路衰竭 | 滚动 Delta 符号翻转时，评价上一方向段的量峰值和 Delta 峰值；成交量与逐笔记录数独立计算 | Cyan 青色三角：成交量实心、记录数空心 |
| 减速 | 局部价格区间的极值侧连续三档 Bid / Ask 量递减，并结合窄幅区间决定可见性 | Gold 金色粗空心三角，可移动、翻向、隐藏和重新出现 |
| 吸收 / 压力 | 窄幅实体区间离开后，依据量过滤、区间 Delta 和离开方向分类；以累计分价 POC、原版价值区或区间边界定位 | AC / AE 虚线，PC / PE 实线；C 为控制线，E 为极值线；绿 / 红反映区间 Delta 正负 |

加速弱 / 中 / 强系数为 3.25 / 4.75 / 6.5；衰竭窗口为 5 / 8 / 10。Range 使用真实 tick 大小推导窄幅阈值，其他周期使用 21 个 True Range 样本，写入超过 21 次后启用。Strong 水平线离开判定使用 High / Low，其余使用 Close。

保留原实现的特殊规则：加速首桶以价格 tick 坐标初始化量和 Delta；候选先进入统计；样本标准差分母 n−1；零 Delta 归非负侧；价值区累计不先加 POC、同量先向下；分类检查 High 是否超过实体上沿。没有替换为 ATAS 通用 POC / 价值区算法。

收柱先维护旧图形，再创建新水平线；新水平线不在同次创建回调内停止。停止条件检查实体严格越界，影线或刚好等于边界不停止。原有 X 轴 +1 柱偏移保留，加速区域左端 +0.5 柱；这些是绘图偏移，不代表信号提前产生。

## 数据要求与平台差异

**本指标需要原始逐笔，不能只靠 OHLC 和柱 Delta 还原。** 历史使用 `CumulativeTradesRequest` 的 Filter 模式，再取每个 `CumulativeTrade.Ticks` 中的单笔成交；实时使用 `OnNewTrade`。累计成交组本身不会被算作一笔。

数据接口依据 [ATAS 成交接收说明](https://docs.atas.net/en/md_DataFeedsCore_2Docs_2en_20025__ReceivingProcessingData.html) 和 [CumulativeTrade.Ticks 文档](https://docs.atas.net/en/classATAS_1_1Indicators_1_1CumulativeTrade.html)。Filter 模式不使用 FilterLimited 的会话数量限制，但历史覆盖仍由数据源决定。

- **逐柱核对**：重建 OHLC、Ask/Bid/总量、可用的 Ticks 笔数，以及完整分价分布。缺少逐笔、分价或核对失败的柱明确记录缺口，撤回其临时信号并重置检测统计；已有确认图形继续按规则维护。
- **盘中预览**：当前柱的加速和减速显示属于预览，可移动或撤回。下一根真实柱出现且核对通过后才提交；尾柱不靠墙钟强制收盘。
- **历史与实时接续**：历史截止于添加 / 重算时当前柱的开始之前。接入时未完整捕获的柱主动跳过，并重新预热；后续完整柱才进入实时检测。相同边界时间戳无法唯一归属时也会跳过，避免重复计数。历史加载期间缓存后续实时逐笔，最多 100 万笔。
- **同时间戳成交**：保留每一笔，不按时间 / 价格 / 数量去重；使用柱时间与成交量预算归属。相同时间戳内的顺序仍取决于数据源，柱核对不能证明与原平台的撮合顺序完全相同。
- **合成柱**：单笔成交跨柱拆分时不伪造新笔数；对应柱视为缺口。Renko、部分 Range 变体或成交量柱可能因此无法产生完整信号。
- **方向缺失**：真实未知方向量仍进入总量加速；流量相关的衰竭、减速和新水平线停用并重置。笔数代表成交记录数，不是独立订单数量。
- **价格和数量**：按合约 TickSize 转为整数价格坐标；需要非负整数手数。不支持小数手数，非 tick 网格价格、溢出及实时倒序会暂停并提示。
- **回看起点**：默认最近 3000 根已收柱；更改起点会改变统计、预热和信号，不能与加载全历史默认视为相同。缺口后的统计同样从头预热。
- **重算与会话**：计算参数变化重建历史，快速连续变更等待旧请求返回后只发送最新请求；颜色和线宽仅重绘。会话取 ATAS `IsNewSession`，只执行原规则的减速区间重置。切换数据提供者或品种重建；无法识别连续合约历史中隐藏的换月。
- **时钟精度**：C++ 的纳秒时间转为 ATAS DateTime 的 100ns 精度；仍按成交时间的一秒间隔划桶，不在无成交时生成空桶。

图上状态提示会报告可见区数据不足的柱数；暂停状态始终显示。若请求失败，可继续等待后续完整实时柱；若输入暂停，处理原因后重新计算 / 重载指标。

## 构建与验证

需要 .NET 10 SDK 和本机 ATAS。依赖来自安装目录和 SDK，无外部 NuGet 包。

在仓库根目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\atas\build.ps1 -Indicator DeepVTracker
# 可指定其他安装位置；-Indicator All 构建两个指标
powershell -NoProfile -ExecutionPolicy Bypass -File .\atas\build.ps1 -Indicator DeepVTracker -ATASInstallDir 'D:\ATAS Platform'
```

输出 `artifacts\DeepVTracker\WolfMoss.DeepVTracker.dll` 和 `artifacts\DeepVTracker-ATAS-1.0.0.zip`。包中含 DLL、PDB、本说明及 DLL SHA256。`-SkipTests` 仅构建打包。

当前 **89 项自动检查**覆盖四类检测器、特殊统计与价值区、实体越界和寿命、同时间戳成交、历史 / 实时回放一致性、分价不符回滚、缺口、原生 ATAS 历史及实时事件接入、加载期间改参数、多次重复回调、图标和线型、裁剪恢复与离屏剔除。集成测试使用真实 ATAS 类型和模拟行情提供者。

尚未在真实 ATAS 图表上完成行情回放和视觉验收，也未用同一份行情与原 C++ 宿主逐信号对照。构柱规则、数据源、成交顺序或历史起点不同仍可能造成信号差异；此版本已完成代码移植、编译和模拟接入验证。仅计算和绘图，没有交易执行、声音或弹窗。

代码分为 `Core/` 检测器、`Adapter/TradeReplay.cs` 逐笔核对及回滚、`DeepVTrackerIndicator*.cs` 平台接入与绘图；测试位于 `atas/tests/DeepVTracker.Tests/`。
