# UW 页面采集助手 0.1.4

0.1.4：新增“导出 HTML 对照报告”。下载后双击 HTML，即可离线按品种、时间桶、看涨/看跌、还原状态及合约关键词筛选。表格显示 Bid / Ask / Neutral 数量、红灰绿比例条、区间成交量和权利金原文；详情保留补算说明、未知原因、原始宽度与版本时间。旧轮次也能导出，无需重新采集。建议先停止采集再导出，同时保留 JSON 完整修订历史。报告是每个合约桶的最新记录集合，不是同一时刻整页快照；与 UW 比较时必须对齐日期、时区、桶和合约。更新前停止采集，在原加载目录更新扩展并刷新控制台与 UW 页面。

0.1.3：缺少颜色不再直接拒绝。已显示两侧与总量可唯一求出剩余侧时，补算并标记 `inference=unique-residual-from-total`。仅一个色段且 CSS 实际宽度为 100% 时，按网站满侧显示约定将其余两侧置零，标记 `single-full-width-assumes-omitted-sides-zero`；这是明确的显示规则假设，不是悬停真值核验。控制台显示补算行数，原始缺段仍保留 null。旧轮次不会自动重新计算，升级后请新建采集。

0.1.2 新增：控制台显示最后一次成功读取页面的未还原原因及行数，每行只计入一个主要原因，轮询不累加。统计同时保存在导出的 `run.lastUnverifiedReasons`。旧轮次没有该统计时显示“未记录”，不补零。升级前先停止正在运行的采集；升级后重新加载扩展、刷新 UW 与控制台并新建采集。

0.1.1 修复：兼容 UW 的 `span[role="button"]` 日期控件；区分未找到日期与多个日期控件的提示，保留日期一致性校验。升级后在扩展管理页点击重新加载，再刷新 UW 页面和采集控制台。不必卸载扩展。

独立 Chrome / Edge 扩展；不依赖 ATAS、IB Gateway、.NET 或 Node。只读取已登录的 Unusual Whales Interval Flow 页面，保存本地数据用于后续对照。未接入现有 IB 分析器，不改变指标或交易算法。不是 UW 官方扩展。

## 安装（一次）

1. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
2. 打开“开发者模式”，选择“加载已解压的扩展程序”。
3. 选择本项目 `tools/UwPageCollector/extension` 文件夹，里面直接有 `manifest.json`。如果使用 ZIP 包，先解压，再选择含 manifest 的目录；不是选择 ZIP 文件。
4. 浏览器扩展菜单中固定“UW 页面采集助手”。
5. 在**同一个 Chrome / Edge 浏览器配置文件**登录 UW，打开 Interval Flow。如果在安装前已经打开页面，请刷新一次，让读取脚本加载。

安装后浏览器会提示可读取 unusualwhales.com 的网站数据：权限仅限该域名；实际自动脚本仅加载 `/interval-flow` 路径。没有账户、Cookies、浏览记录、调试器、网络拦截权限；不读取页面内部状态或隐藏接口，不收集登录凭证，不上传任何数据。请在符合数据供应商许可及使用约定的前提下使用。

## 每次采集

1. 在 UW 设置好品种、到期日筛选、结果数量和时间桶。确保 `Interval`、`Ticker`、`Contract`、`Interval Vol`、`Interval B/A` 列存在。
2. 点击扩展图标，打开中文控制台。多个 UW 页面时按标签页编号选择目标，一次只采集一个页面。
3. 手动填写 UW 日期按钮对应的**页面日期**（不是期权到期日），并确认 UW 页面显示时区。纽约时区自动处理夏令时。不能仅凭电脑时间或网址猜测。
4. 阅读并勾选确认，点击“开始采集”。默认每 5 秒读取本地已加载表格，不主动请求 UW API，不刷新网站。
5. 可关闭扩展控制台，保留 UW 页面和浏览器。建议避免电脑睡眠，注意后台标签页可能被降频、冻结或丢弃。
6. 结束时重新点扩展图标，选择轮次，点“停止本轮”，再“导出 JSON 数据包”。文件通过浏览器下载，通常在“下载”文件夹。
7. 确认导出成功后才删除本轮。删除有二次确认且不可撤销；卸载扩展也会丢失未导出的数据。更新扩展时建议固定使用同一个加载目录并先备份。

### 第一次建议做 1–2 分钟短测

- 状态应出现“正在读取页面”，合约时间桶数量不为零，最后读取时间推进。
- 同一桶没变化时，变化快照数量不必增加；这不是故障。
- 找一条页面悬停值，与导出中同一日期、时区、桶、到期日和合约的 `latest[].ba.counts` 对照。正在形成的桶可能在悬停之前已变动，需要对齐快照时间。
- 停止并导出；确认 JSON 中有 `run`、`latest`、`revisions`。后续可以把文件交给分析程序或本任务检查。

## 数据含义与限制

- B/A 使用**成交数量**，不是权利金权重。Neutral 不等同于我们的方向分析“未知”。`Premium` 等页面字段保留原文，K/M 和均价均可能被舍入，不当作精确美元金额。
- 本扩展不自动悬停。通过 Interval B/A 色条的 CSS 百分比还原整数：每侧允许最后显示小数位 ±1 单位的保守容差，再结合三侧合计等于 Interval Vol 的约束。只有唯一整数解才输出 `RECONSTRUCTED`。该标记不是 tooltip 人工核验，也不是官方原始成交真值。
- 缺段无法补算、非法百分比、多个整数解或合计冲突时保留 `UNVERIFIED`、原因和原始字段，`counts` 为 `null`。单侧满宽按上述规则处理；其余缺段通过总量约束补算，不一律填零。整条色条缺失仍为未知。
- 按表头定位 `Interval B/A`，不会误读 `Total B/A`，不依赖重复的 DOM id。实际桶宽度取表格显示，不将 URL `interval` 数字当分钟数。
- 唯一键：品种 / 交易类别标签、到期日、Call/Put、执行价、UTC 起止。SPXW 不折叠为 SPX。UTC 根据用户确认的页面日期和时区转换。
- 每次内容变化增加修订，`latest` 是各桶最后观察到的版本，`revisions` 是全部变化历史。**不得把各次快照的成交量相加，也不得把 latest 与 revisions 相加。** 完全重复内容不再存一份。最新记录的时间表示该版本被记录的时间，不是最后一次重复看见它的时间。
- `FORMING` = 接收时桶尚未结束；`ENDED_NOT_FINAL` = 接收时已过结束时间，但可能被 UW 修订，**不保证最终值**。初次只看到已结束桶也不意味着采集了整个形成过程。
- 只读取当前 DOM 已加载的行，不自动翻页或追溯历史。被筛掉、排在结果上限之外、尚未加载或已移出页面的合约不会被补齐，缺失不表示零。页面读到 150 行不意味着完整市场覆盖。
- 日期按钮、URL 或列结构变化立即停止；页面刷新、导航重载、关闭或浏览器重启不自动恢复。原数据保留，需新建采集。请勿在运行中改变页面时区（页面未暴露统一可读的时区标识，程序不能可靠检测此项）。
- 第一版不猜测跨午夜桶或夏令时回拨的歧义时间；遇到即停止并提示。只支持设置中列出的三种显示时区。
- 内容不变无法区分“真实无更新”与“上游静止”，控制台分开显示最后读取与最后变化。心跳间断是本地观察缺口，不是已证明漏单数量。
- 空表记录为空表，不补零。必需表格丢失或行解析异常停止，保留之前的数据。存储故障会终止页面循环；极端情况下数据库无法写入停止状态，控制台会显示读取间断，需人工检查。
- 每轮最多 64 MiB（按修订序列化估算，不含数据库索引及最新值副本）。100 轮或历史合计 256 MiB 后不再新建；已有一轮可以继续到自身上限。导出会暂时占用更多内存。没有申请无限存储权限，浏览器磁盘配额可能更早耗尽。

## 导出格式 `uw-page-collector/1`

`run`：版本、确认配置、原始页面 URL、日期标签、表头、启动/停止原因、读取/间断统计。

`latest`：每个合约时间桶最后观察版本，包含 `identity`、`bucket`（本地及 UTC）、`volume`、`ba`（状态、原因、区间和数量）、`raw`（原百分比及表格字段）、`capturedUtc`（后台接收）、`pageReadUtc`（页面读取）、`revision`、`timeState`、`volumeDecreased`。

`revisions`：各变化版本，加单调递增 `sequence`，便于重复分析与审计。序列不会因为重启 service worker 而清零。

离线对比 UW 与 IB 时，应先对齐合约、交易日、时区、桶边界和按量/按权利金口径；不要直接把本工具的 Neutral 当作 IB 分类的未知，也不要宣称 UW 数据证明了真实主动方。

## 开发和测试

运行包 `extension/` 全部是本地 JS/CSS，无构建步骤、无运行时第三方包。测试依赖只放在开发目录，锁定于 `pnpm-lock.yaml`。

```powershell
pnpm install --frozen-lockfile --ignore-scripts
node --test tests/*.test.cjs
node tests/benchmark.cjs
powershell -ExecutionPolicy Bypass -File .\Publish-Collector.ps1
```

`node tests/preview.cjs` 在 `127.0.0.1:8769` 提供**仅模拟**界面预览，不采集真实 UW。该服务及 mock 不进入扩展运行包。

已做解析、DOM 结构、IndexedDB、模拟 Chrome 消息与生命周期测试；模拟界面检查不能代替真实浏览器扩展安装验证。安装完成后执行上述短测，再投入正式采集。

实现参考：[Chrome 内容脚本](https://developer.chrome.com/docs/extensions/develop/concepts/content-scripts)、[扩展权限](https://developer.chrome.com/docs/extensions/develop/concepts/declare-permissions)。
