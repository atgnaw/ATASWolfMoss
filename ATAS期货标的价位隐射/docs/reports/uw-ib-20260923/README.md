# 2026-09-23 UW / IB 对照结论

分析对象：用户提供的 UW 0.1.4 导出，和 IB 原始运行 `20260923-172906-fb42980f991c4d29b4e613d93ca99d91` 的 0.6.0 双开关逐笔证据。原始文件与原报告未修改。

## 对齐和比较口径

- 纽约时间 13:30–13:55，5 个完整的 5 分钟桶。明确排除用户指定的 13:55–14:00；13:25–13:30 及更早的桶不在 IB 完整观察期内。
- 按品种、到期日、执行价、Call/Put、桶起止精确连接；仅在合约类别已验证为 SPXW 的 IB SPX 合约上映射 UW SPXW。
- 共 20 个合约、100 个合约桶（QQQ 50、SPX 50）。UW 所有配对记录都有结束后保存版本；其中 1 条含缺段补算。剔除该条后排名不变。
- UW 使用 latest，每桶最后保存版本；不累加 revisions。UW 仍是页面比例还原，结束后保存不保证供应商不再修订。
- 按成交数量而非权利金比较。IB 从原始 RT 字符串取 size，按 sequence 与已生成的 0.6.0 decisions 对接，仅使用 ACCEPTED 成交；不是把最后一笔方向分配给累计增量。
- 233 和 375 分别分析。Ask 对应买、Bid 对应卖、Neutral 对应 Mid；未知独立为第四类，绝不合并进 Neutral。
- 主指标：每桶四类占比分布距离 = `Σ|IB比例−UW比例|/2`，再按 UW 桶成交量加权，越小越近。分布距离不是逐笔误判率或准确率。附每桶等权结果和净方向误差防止只看总量抵消。
- 净方向差采用 `(Ask−Bid)/总量`；这与原报告按权利金及只除以买卖金额的“倾向”口径不同。
