## 共享边界

统计组键：连接身份 + ticker + expiration + 固定/滚动 + 分钟周期 + 成交口径 + 请求档数。

- 同组共用样本、累计基线、观察段和不可变快照；同一回调扇出到多个图表时只接收一次。
- 同组后来加入的图表直接使用已有统计；不同设置的新组从创建后开始观察，不从其他组回补历史。
- OI 是否显示、列宽、状态显示时区不属于分组键。
- 不同组独立统计，但都使用第二批统一的品种接收范围，因此 1m 与 5m 组不会各占一套 ATM 行情线。
- 最后一个组消费者释放时删除整组缓存；部分消费者停止时其他消费者仍可继续收数。
- UI 发布使用同组缓存，正常轮询之间允许短暂刷新时差，并非保证两张图表同一屏幕帧重绘。映射轴比例及图表 Y 坐标仍属于各图表。

## 分段覆盖语义

固定桶保存本桶首次确定的统计梯级；统一接收范围在桶内换档，不重写这个桶的梯级。
退出范围的合约停止接收；桶内已确认的差值保留。重新进入时建立新观察段，不能跨缺口相减。
例如旧段确认 10 张，新段确认 5 张，结果为 15 张，未订阅期间累计计数器增加的成交不算入。

Rolling 同样分段累计，旧范围的确认值自然滚出窗口；其顶部／悬停中的 ATM 锁定截止改用共同接收边界，不再展示私有 N 分钟锁。
两种模式均支持 1、3、5、10 分钟。没有成交事件仍为 NO EVENTS；有事件但不足以确认差值为 NO DATA。
迟到首笔可用时采用已确认成交或后续累计差值，标记 PARTIAL。没有使用历史 bar 回补。

断线后保留相同目标的已发布帧，观察恢复建立新基线。交易区段之间不串接，残缺固定桶不发布。
校时使用墙钟与单调计时器判断并重建组基线；普通回调／发布抢锁导致的时间先后颠倒不会清空整组。

## 验收重点与保留事项

1. 同连接的两张 QQQ 图表设同样模式、周期、口径、档数：已完成桶时间、数值和覆盖标记应一致；允许约一个轮询周期的 UI 刷新差。
2. 将一张改为 5m、另一张为 1m：接收范围按 1m 协调，但桶统计各自保持 5m／1m。
3. 同设置第二张图表后来加入，应复用已有 Flow 数据，不重新等待整个周期。
4. 换档后的重入、短暂断线和不同组之间，不能出现跨未观察区间的巨大虚假累计差额。
5. PERF 样本数现在反映该统计组的缓存，不要把两张同组图表的样本数相加。各图表输入诊断仍为本图表回调计数；共享重复／关闭观察段归入边界拒绝，不能据此单独判断上游缺数。
