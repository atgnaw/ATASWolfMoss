## 已实施

- 分类与对齐分离：3 种分类方法 × 3 种对齐模式均可组合。原保守主结果改为“中间价法＋多时间候选一致”的快捷预设。切换分类方法保留当前年龄阈值或源时间偏移。
- 保留原 36 个基础场景，新增各方法的一致性结果及逐笔证据。源候选不足、方向冲突、候选未解决独立归因；时间冲突诊断在其他候选未知时仍计数。
- 未知原因固定 U01–U25 编号/颜色，U99 为兼容保护。细分报价数量、报价标记、锁盘/交叉及五种逐笔补判不足原因。每个场景每笔最多归一个主原因，按权利金聚合，同时记录笔数。
- 每行未知色条以未知权利金为分母，点击显示定义、例子、金额、笔数和两种占比。所有原因可从底部图例查阅。没有未知及无成交样本分别显示。
- 主表分开展示：倾向、分类覆盖、未知边界、六个时间场景的倾向范围、逐笔时间冲突占比、抗误判余量。六场景范围使用最新无年龄限制及五个源时间偏移，只包含有倾向分母的场景，并显示可计算场景数量。
- 浅色研究报告布局、买卖未知构成条、覆盖条、带零轴的范围条；默认纽约时间，支持北京时间/新加坡及 UTC；金额以万/亿展示。
- 主要名词和方法设置都有可点击解释，含公式与例子；大面积质量/详情列改为末尾小按钮，弹窗内用中文表格展示证据与压力结果。
- 页面分页 50 行，窄屏仅表格横向滚动；说明弹窗支持键盘 Escape、按钮焦点及色段可访问标签。没有外部字体、脚本或网络请求。
- HTML 只嵌入展示所需数据，完整技术证据保留在 JSON 和逐笔文件。输出 schema 3，原始 schema 1 兼容；始终生成新目录。
