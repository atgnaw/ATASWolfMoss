# 独立验证报告 U25 原因展开（0.5.1）

本次仅修改独立 IbOptionFlowProbe 及测试，不改变 ATAS 指标、IB 采集接口或方向判定规则。

## 阅读入口

点击某行未知原因色条的 U25 → 原因组合 → 真实成交示例。详情小按钮也提供相同入口。

- 组合以必要候选中无法判断的原因集合划分，每笔成交只进入一个组合。
- 比例分母为该行 U25 权利金，合计 100%；多原因组合不重复分配金额。
- 每个组合最多嵌入前两笔真实示例，显示成交价、权利金、原始序号、源时间、接收时间及实际参与判断的候选买卖报价。
- 时间显示到毫秒；不使用后到报价，不把不同候选当作独立证据，不将示例当作全部样本。
- 未改变原始数据及旧报告；新增字段保持报告 schema 3，算法版本标识 0.5.1。
