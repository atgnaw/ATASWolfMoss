# Pro 2.3.0 状态 UI 分类与独立 Flow 倒计时

## 设置

新增 `Status UI / 状态信息` 组，六个 bool 设置默认 true：

- `ShowMappingStatus`：映射轴信息。
- `ShowHeatmapStatus`：Heatmap 信息。
- `ShowDealerGexStatus`：Dealer GEX 信息。
- `ShowOptionOiStatus`：Option OI 信息。
- `ShowOptionFlowStatus`：Option Flow 信息。
- `ShowPerformanceStatus`：性能与输入诊断信息（PERF/CLOCK/FLOW 接收诊断/ATM 协调）。

这些开关均为纯 UI 设置。真实功能关闭后，该功能仍不显示状态信息；
性能诊断为 Off 时不会因开启性能文字开关而开始采样。
隐藏性能文字不改变 Summary/Record 模式，也不会停止 Record 文件。

`StatusPanelWidth` 默认 480，范围 180–1600 像素，运行时也强制限幅。
保持现有总开关、水平/垂直偏移以及文字/边框/背景颜色设置。
面板受图表可用宽度约束，长文本按实际字体测量换行；
高度不足时最后一行明确提示“信息未显示完”，可减少分类、加宽面板或增高图表。
全部分类隐藏时不画空状态框。

## 倒计时语义

- 仅当 Option Flow 功能开启时显示；它有独立边框，和状态框间隔 6 像素。
- 状态总开关关闭或所有分类隐藏时，倒计时使用原状态定位，不随状态文字一起隐藏。
- 固定模式：例如 `Flow 5m 桶 04:59`，表示当前形成桶距结束的时间，
  不是当前柱形所显示的上一已完成桶。结束后仍按原有 3 秒缓冲发布数据。
- 滚动模式：例如 `Flow 5m ATM 00:59`，表示品种协调器下一次 ATM 换档倒计时。
  同时有 1m 和 5m 配置时，5m 滚动列的 ATM 倒计时也遵循统一 1m 节奏。
  滚动窗口本身没有固定终点，不显示虚构的“滚动桶结束时间”。
- 根据 IB 实际交易区段计算。区段末尾不足完整固定桶时显示说明，不倒计时到休市之外。
  休市、等待时段/换档、无合约、故障暂停有不同提示。倒计时不代表行情一定有成交或有数据。
- 使用实际 UTC，和图表时区无关，不用已完成快照的旧 BucketEnd 来计算新桶。

## 性能与兼容性

- 换行与文字测量按内容、宽度、字体及可用高度缓存，未变化的绘制路径不创建测量闭包。
- 倒计时文字按秒和状态缓存。网络数据所有者发布只读交易时段引用；绘图不解析合约、不等待数据锁、不请求 IB。
- Flow 开启时增加一个受监测的 1Hz UI 唤醒循环，不增加行情线或 API 请求。
  Flow 关闭、指标销毁时取消；异步任务异常有明确观察者。
- 普通版仍为 1.1.0，不增加公开设置和功能。共享基类只把状态绘图改为可覆写扩展点，
  并开放受保护的映射状态文字读取，普通版绘制逻辑未变。
- Pro 保持 2.3.0 与原程序集/指标类型名称不变。

## 验证

Release 构建零警告、零错误；126 组离线测试通过（原 121 + 新增 5 组）。
新增覆盖六类开关全部 64 种组合、缓存复用、默认值/限幅、订阅与 Flow/Record 隔离、
窄面板换行、上下定位、1/3/5/10 分钟边界、GTH/维护间隔、区段尾部、Rolling 统一节奏及计时循环释放。

没有连接真实 IB/Nightwatch，没有部署或重启 ATAS。本次仍需人工验收：

1. 关闭各类状态文字，确认对应数据列与统计继续运行；关闭性能文字后检查 Record 仍写文件。
2. 宽度设置 300/480/800，调整图表高度与状态偏移，确认换行和最下方独立倒计时不重叠。
3. 关闭状态总开关，确认倒计时保留；关闭 Flow，确认倒计时消失。
4. 固定 1m 和 5m 检查跨分钟递减/复位；Rolling 5m 与另一张 1m 图同时运行时，确认 ATM 倒计时跟随统一节奏。
5. 退出 ATAS 后替换 DLL 再启动，避免宿主继续使用已加载的旧程序集。
