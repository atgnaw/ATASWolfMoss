# UW 页面采集扩展 0.1.0 — 阶段交付

日期：2026-09-22。独立于现有 ATAS 指标、WolfMoss.IB 及 IbOptionFlowProbe。

## 已实现

- Manifest V3；Chrome/Edge 加载已解压扩展；全中文独立控制台。
- 显式开始/停止；手动确认页面日期及时区；默认 5 秒读取一次已渲染 DOM。
- 表头定位、合约身份、页面真实桶宽度、DST 转换；拒绝跨午夜/歧义时刻猜测。
- 色条百分比 BigInt 整数区间求解：缺失、精度不足、不一致均保留未知；单条人工核验样本得到 Bid 6401 / Ask 7060 / Neutral 77。
- IndexedDB 原子写入；最新版本 + 全部变化版本；重复不累加，容量保护，JSON 导出，人工确认删除。
- worker 重建不丢运行状态；文档实例绑定；关闭/刷新/切换日期或 URL 后停止；重启不自动采集；旧回调不影响新一轮。
- 读取/内容变化时间、间断、页面后台状态分开显示；不把结束桶宣称为最终定稿。
- 不请求 UW API、读取 Cookies、访问隐藏应用状态、自动登录或自动翻页。不启动 IB 连接。

## 检查结果

`node --test tests/*.test.cjs`：18 项通过，0 失败（解析与 DOM、日期/时区、数据版本、事务失败、容量限制、来源与文档绑定、重复启动、worker 重建、页面关闭、浏览器重启）。

真实 UW DOM 只读复核：150 条数据行，表头 23 列；Interval B/A 色段 class 与前次一致；Contract 含换行，解析器会规范化空白。没有在真实页面安装扩展或启动长期采集。

内置浏览器上的本地模拟 UI：开始/停止、日期及下拉选择、计数卡片、状态切换可见；检查时无控制台 error/warn。模拟页面不是扩展实际安装验收；没有把模拟数字称为实测市场数据。

解析微基准（500 次 × 150 行）：Intel Core i7-12700H，Node v24.19.0；均值 1.09 ms / P95 1.46 ms 每 150 行，进程结束采样 RSS 57.5 MiB。只测纯解析，不含真实浏览器 DOM、IndexedDB、网络或长期内存稳定性；不得据此宣称整套扩展开销或采集完整性。

## 仍需用户安装后的验收

1. Chrome/Edge 中加载扩展、刷新已登录的 UW 页面。
2. 1–2 分钟短采集，确认读取时间推进、停止、JSON 下载。
3. 选择匹配时间与合约的记录，人工悬停核对更多样本；未唯一还原保留 null。
4. 正式开盘验证页面上游刷新、后台节流与目标合约是否被结果上限排除。

本期不含 UW/IB 对照报告导入器、自动参数训练或生产方向指标接入。
