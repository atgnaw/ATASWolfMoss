# 固定时间桶 Flow：主动买入强度（Pro 2.4.2）

## 2.4.2：灰色未知诊断与恢复

- 行情中断后仍须重新确认行情类型并收到有效报价；不能凭普通报价猜测为实时行情。超过 5 秒未确认时，经现有维护节奏限速取消旧订阅、重建同一合约订阅，保留 375/233 需求，不新增重复行情线。
- 未确认重试间隔至少 30 秒、最多 3 次；行情服务恢复通知会重新开放重试。已确认的延迟/冻结行情不冒充实时，也不无限重试。若仍显示“行情类型未确认”，请检查 Gateway 连接、行情权限及错误提示。
- 本机时钟校正、交易时段切换仍丢弃旧报价，但不抹掉同一订阅已经明确确认的行情类型。中断桶保持不完整；新完整桶恢复后才能正常着色。
- 悬停优先显示中间价未知的原因、张数和占未知张数比例：行情类型未确认、非实时行情、报价缺失、价格无效、盘前/越界标记、挂单数量无效、买卖价交叉、时段不一致。每笔只计一个主要原因，因此原因张数不重复。
- 贴价法价差内成交不定向，独立列出张数，避免误认为连接故障。所有诊断均为固定数量的内存计数，不保存逐笔历史。
- 本次修复针对代码中确认的恢复缺口，不表示已确认此前凌晨 2:30 的现场触发原因。新统计不会补回升级前已丢失的分类；实盘跨时段验证仍需现场观察。

## 如何开启

在 Pro 指标设置的 **IB Gateway / 期权数据** 中：

1. 开启“显示权利金与成交量”。
2. 时间桶模式选择 `PreviousCompletedFixed`（上一段已完成固定桶）。
3. 开启 **“显示主动买入强度”**，默认为关闭。
4. 等待从头观察完一个时间桶。中途开启所在桶会显示灰色 `?`，不会补造历史方向。

周期跟随原 Flow，可为 1、3、5、10 分钟。完成后仍沿用原来的 3 秒发布宽限。滚动模式不会应用本功能，悬停会说明仅支持固定桶。

## 怎么读图

| 项目 | 含义 |
|---|---|
| 条长及原有金额标签 | 原 Flow 权利金，计算方式和用户选定的 375/233 口径不变 |
| Call 绿色、Put 红色的亮度 | 中间价法买量 /（买量＋卖量），按成交张数统计；0% 最暗，100% 最亮 |
| 灰色 `×` | 中间价法与贴价法的买方占比差超过 **1 个百分点** |
| 灰色 `?` | 缺少买卖参考数据、没有方向数据，或本桶观察不完整 |

灰色只是显示抑制，不将原始成交分类改成中性、不清零金额、不伪造 50% 比例。条很小时以小型浅灰标记提示，具体原因见悬停。Put 更亮表示更多主动买入 Put，**不代表看涨**。

亮度使用固定色阶，同样的买方占比在不同执行价、不同时间桶具有同样的颜色。颜色不是由同屏最大值归一化。此强度不是交易数量大小，也不是准确率。

若金额选择 **375 常规成交**，条长仍使用 375，但颜色始终独立使用 **233 全部成交**。悬停分别注明两种口径，不应把颜色解释为仅针对条长所代表的那部分成交。

## 固定算法

- 233 对应的成交回调；与 Probe 相同的基线、重复、乱序、修订、累计值重置等逐笔接纳规则。
- 成交按源时间进入固定桶；分类使用本地收到该成交时已有的最新报价，不使用后来到达的报价。
- 报价无年龄上限，但仍要求有效的实时 Bid/Ask 及数量，拒绝交叉或无效报价。
- U15 固定开启：成交高于 Ask 判买，低于 Bid 判卖。
- 中间价法：价差内部成交高于中间价判买、低于判卖、等于判中性。锁定报价按 Probe 规则判中性。
- 贴价法：价差内部成交不判买卖。
- 过滤：`abs(中间价法买/(买+卖) − 贴价法买/(买+卖)) ≤ 0.01` 才显示强度色。
- 中性和未知均不进入买方占比分母；两方法无买卖参考量时不自动放行。不额外加入覆盖率或成交量门槛。

悬停显示两种买方比例、方法差、买卖分类覆盖率、233 分类张数及状态。当前 1 个百分点阈值只经过 **5 分钟桶**研究，其余周期属于扩展使用。两方法一致并不能证明方向正确，也不表示交易所提供了主动买卖标识。

## 订阅与性能

- 233 与 375 在同一合约的一个 `reqMktData` 请求中合并，不因两种字段双开行情线。开启时可能需要取消并重建原订阅，本桶按不完整处理。
- 最新报价、两种分类及四种周期的累计在共享接收层处理一次，图表只读取结果。即使多图表、不同金额口径同时使用，也不按图表重复累计。
- 最新报价不保留历史列表。每合约最多保留 12 个桶（四种周期，每种最多三个）；已移出范围的状态为有界短期缓存，最长保留 30 分钟、最多 512 个合约，最后一个方向需求消失时清理。
- 颜色/标签随已完成桶缓存，绘图不遍历成交、不重新分类、不联网、不写文件。关闭时不为本功能额外订阅 233，也不创建方向分类状态。
- 回调后的跨桶迟到成交不会改写已经封存的显示桶；断线、时钟跳变、订阅代次变化和无效样本会打断完整性。已完成的上一桶可以保持展示，但不代表新桶仍正常采集。
